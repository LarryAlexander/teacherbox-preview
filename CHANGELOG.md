# Preview changelog

## 2026-10-06 — TeacherBox v34 no-login feedback form

TeacherBox v34 adds an optional Google Forms route for teachers who prefer not to post on GitHub:

- Submit the [TeacherBox Preview Feedback form](https://docs.google.com/forms/d/e/1FAIpQLSdGBLhPmdePHehzPfEngNtAuO7Q170Zy6uUy1hU9FMrziv-lQ/viewform) without signing in. Google sign-in is optional for saving progress.
- Choose from bug, usability, idea or feature request, accessibility, classroom workflow, onboarding, or other feedback.
- Contact information is optional; an email address is requested only if you want a reply.
- Google processes submissions, which are stored with the private form and its linked response sheet for the TeacherBox owner to review.

Do not include student names, school names or identifying details, grades tied to a student, personal details, screenshots, or other sensitive information. The form does not access or include work saved in the TeacherBox browser.

## 2026-10-06 — TeacherBox v33 feedback routing

TeacherBox v33 adds a feedback entry point that guides preview users to the public GitHub hub:

- Report a bug with the [bug report issue form](https://github.com/LarryAlexander/teacherbox-preview/issues/new?template=bug-report.yml).
- Share an idea in [Ideas](https://github.com/LarryAlexander/teacherbox-preview/discussions/categories/ideas).
- Ask a question in [Q&A](https://github.com/LarryAlexander/teacherbox-preview/discussions/categories/q-a).
- Use [General](https://github.com/LarryAlexander/teacherbox-preview/discussions/categories/general) for a brief introduction or to say what you plan to try.

The preview is open without a TeacherBox account, application, approval, or waitlist. Posting on GitHub is optional and requires a GitHub account. Issues and discussions are public and associated with the poster's GitHub identity. **Never include student-identifying or other sensitive information in a post or screenshot.** See the [participation instructions](README.md#optional-participate-or-share-feedback-on-github) for details.
