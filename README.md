# TeacherBox Preview

[Open the TeacherBox preview](https://teacherbox.lathekid.chatgpt.site). The preview is currently open: you can use it now without a TeacherBox account, an application, approval, or a waitlist.

## Try TeacherBox

Visit [teacherbox.lathekid.chatgpt.site](https://teacherbox.lathekid.chatgpt.site) and explore the preview. Trying the app does not require signing up.

## Optional: participate or share feedback on GitHub

You only need a GitHub account if you want to post. If you do not have one, [sign up for GitHub](https://github.com/signup), then sign in. Participation on GitHub is optional and does not control access to the TeacherBox preview.

After signing in, open the relevant public area and choose **New discussion** or **New issue**:

- **General:** [introduce yourself briefly or say what you plan to try](https://github.com/LarryAlexander/teacherbox-preview/discussions/categories/general). You do not need to share your real name, school, or contact information. This is an optional public post, not an application, waitlist, or access request.
- **Ideas:** [share a feature idea](https://github.com/LarryAlexander/teacherbox-preview/discussions/categories/ideas).
- **Q&A:** [ask a question](https://github.com/LarryAlexander/teacherbox-preview/discussions/categories/q-a).
- **Bugs:** [open the bug report form](https://github.com/LarryAlexander/teacherbox-preview/issues/new?template=bug-report.yml).

**Privacy reminder:** GitHub issues and discussions are public and associated with the GitHub identity that posts them. Never include student names, student work or grades, details that could identify a student, or other sensitive or private information. Check screenshots for identifying details before attaching them, and review every post before submitting.

## Saved work and weather

TeacherBox keeps saved activities and settings in the browser you use. It does not provide account-based or cross-device syncing. Clearing that browser's site data can remove locally saved work.

When you enter a ZIP code for a weather lookup, TeacherBox sends that ZIP code to [Open-Meteo](https://open-meteo.com/) for a location search. The selected location is then used to request the forecast. Weather requests do not include your saved lessons or activities.
