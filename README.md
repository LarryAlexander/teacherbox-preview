# TeacherBox Preview

[Open the TeacherBox preview](https://teacherbox.lathekid.chatgpt.site). The preview is currently open, and you can try it without creating a TeacherBox account. There is no application or approval step to get access.

## Try it and participate

- **Try TeacherBox:** [teacherbox.lathekid.chatgpt.site](https://teacherbox.lathekid.chatgpt.site)
- **Share that you are participating or what you hope to try:** use the [General discussion](https://github.com/LarryAlexander/teacherbox-preview/discussions/categories/general). This optional post is public; it is not a waitlist or access request.
- **Report a bug:** [open the bug report form](https://github.com/LarryAlexander/teacherbox-preview/issues/new?template=bug-report.yml).
- **Share an idea:** post in [Ideas](https://github.com/LarryAlexander/teacherbox-preview/discussions/categories/ideas).
- **Ask a question:** post in [Q&A](https://github.com/LarryAlexander/teacherbox-preview/discussions/categories/q-a).

To post an issue or discussion, GitHub requires a GitHub account. Participation is optional. Issues and discussions here are public and associated with the GitHub identity that posts them. Review your post before submitting.

## Privacy and saved work

TeacherBox keeps saved activities and settings in the browser you use. It does not provide account-based or cross-device syncing. Clearing that browser's site data can remove locally saved work.

When you enter a ZIP code for a weather lookup, TeacherBox sends that ZIP code to [Open-Meteo](https://open-meteo.com/) for a location search. The selected location is then used to request the forecast. Weather requests do not include your saved lessons or activities.

**Never include student names, work, grades, school or classroom details that could identify a student, or other sensitive or private information in a GitHub post.** Do not attach screenshots until you have checked them for identifying details.

## What this repository contains

This repository contains preview instructions and GitHub feedback forms only. It does not contain TeacherBox application source code or a copy of the app.
